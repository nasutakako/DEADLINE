# DEADLINE

鬼から逃げ切れ。ブラウザですぐ遊べる逃走アクション DEADLINE シリーズ。

| ゲーム | 内容 |
| --- | --- |
| [DEADLINE1](deadline1/) | 2D。閉じ込められた地下から脱出し、夜の街へ。シリーズの原点 |
| [DEADLINE2](deadline2/) | 2D。近未来の隔離区画から脱出し、ネオン街へ |
| [DEADLINE 3D](deadline3d/) | 3D。2階建ての建物に入り、階段や窓を使って鬼をまく |

## 遊び方

- スマホは横向きがおすすめ。左のスティックで移動、右のボタンでダッシュ・爆弾・アイテム
- PC は矢印キー / WASD で移動、Space でダッシュ、E で爆弾、Q でアイテム
- ステージ1をクリアするとステージ2、ステージ2をクリアするとステージ3「終わらない夜」が解放される
- 最初に名前を登録すると、ステージ3の逃走時間で世界ランキング(上位100位)に参加できる

## 世界ランキング

Firebase(匿名ログイン + Cloud Firestore)を使う。設定は `fb.js`、データベースのセキュリティルールは `firestore.rules`(Firebase コンソールの Firestore → ルールに貼って公開)。

## 公開

ビルド不要の静的サイト。GitHub Pages で `main` ブランチのルート (`/`) を公開すれば、そのまま遊べる。
